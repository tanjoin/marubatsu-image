# marubatsu-image

ブラウザー上で画像に丸・バツ・図形・文字などを書き込み、PNGで保存できるシンプルな画像エディターです。

## 使い方

1. `index.html` をブラウザーで開きます。
2. 「画像を開く」から画像を選ぶか、画像を画面にドラッグ＆ドロップ、または画像をコピーして `Ctrl+V`（macOSでは `⌘+V`）で貼り付けます。
3. 左側のツールを選び、画像上でドラッグして描画します。画像の一部にぼかしを入れたい場合は、モザイクツールで範囲をドラッグします。
4. 右上の「保存」を押すと、編集後の画像をPNG形式でダウンロードできます。

編集内容がある状態で別の画像を読み込むと、現在の編集内容を破棄してよいか確認されます。

## ツール

| ツール | 操作 |
| --- | --- |
| 選択・移動 | 図形や文字をクリックしてドラッグし、位置を変更 |
| マル、バツ、四角形、矢印 | 画像上をドラッグして描画。短くクリックするとスタンプとして配置 |
| テキスト | 画像上をクリックして文字を入力し、`Enter` で配置 |
| モザイク | モザイクをかける範囲をドラッグ |

上部のコントロールから色、線の太さ、スタンプ・文字のサイズを調整できます。縦横比固定を有効にするか、描画中に `Shift` キーを押すと、対象の図形を正方形に描画できます。

## キーボードショートカット

| キー | 操作 |
| --- | --- |
| `V` | 選択・移動 |
| `O` | マル |
| `X` | バツ |
| `S` | 四角形 |
| `A` | 矢印 |
| `T` | テキスト |
| `M` | モザイク |
| `Ctrl+Z` / `⌘+Z` | 元に戻す |
| `Ctrl+Y` / `⌘+Y` | やり直す |

## 動作環境

インストールやビルドは不要です。`index.html` をモダンブラウザーで開いてください。Tailwind CSS と Font Awesome をCDNから読み込むため、画面のスタイルとアイコンの表示にはインターネット接続が必要です。
